# BoloLocal

**Speak naturally. Connect meaningfully.**

BoloLocal is a browser-based language learning assistant that helps users practise Hindi, English, and Rajasthani through real-world conversations and cultural guidance.

### Features
- Interactive conversation practice
- Multilingual phrase learning
- Voice input and speech playback
- Multiple proficiency levels
- Cultural etiquette and contextual phrases
- Practice scores and interactive quizzes

### Tech Stack
HTML, CSS, JavaScript, and Web Speech APIs.

No AI models or AI APIs used. Conversations run on predefined phrases and rule-based logic.

### Run Locally
1. Clone the repository.
2. Open the folder in VS Code.
3. Install the Live Server extension.
4. Right-click `BOLO LOCAL.html` and select **Open with Live Server**.

Developed for CS Tech Day Hackathon 2026 at Poornima College of Engineering, Jaipur.
